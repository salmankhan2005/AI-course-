# AI Course Generator & Learning Platform

An AI-driven interactive education platform that allows users to instantly generate, customize, and study structured courses on any topic.

## Features

- **AI Course Generator**: Generate structured modules, chapters, and curriculum from any topic prompt.
- **Interactive Course Player**: Step-by-step chapter navigation, code snippets, and learning checkpoints.
- **Explore & Community Courses**: Browse popular courses and shared learning paths.
- **Personal Dashboard**: Track course progress, completion status, and personal learning roadmaps.

## Tech Stack

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Lucide Icons, Shadcn UI
- **Routing & State**: React Router, TanStack Query
- **Styling**: Tailwind CSS & Tailwind Animate

## Getting Started

### Prerequisites
- Node.js (v18+) & npm

### Installation & Run Locally

```bash
# 1. Clone repository
git clone https://github.com/salmankhan2005/AI-course-.git

# 2. Navigate to project directory
cd AI-course-

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev
```
